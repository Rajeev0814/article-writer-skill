# Article Writer Skill

An AI-powered article writing skill that guides content creation through a structured 5-stage pipeline. Seamlessly publish to multiple platforms with a single workflow.

## Features

- **5-Stage Pipeline**: Intake → Research → Generate → Validate → Review
- **Multi-Platform Support**:
  - Medium
  - Dev.to
  - Substack
  - Ghost
  - Hashnode
  - Beehive
  - LinkedIn
- **Structured Workflow**: Ensures quality and consistency across all content
- **Universal Craft Framework**: Built on proven content creation methodologies

## Getting Started

### Prerequisites
- Python 3.8+
- Access to Claude API

### Installation

```bash
git clone https://github.com/Rajeev0814/article-writer-skill.git
cd article-writer-skill
```

## Pipeline Overview

### 1. Intake (1-intake.md)
- Gather topic ideas and initial requirements
- Define article scope and target audience
- Set content guidelines

### 2. Research (2-research.md)
- Conduct deep research on the topic
- Gather sources and references
- Prepare research materials

### 3. Generate (3-generate.md)
- Create article outline
- Write the full article
- Format and structure content

### 4. Validate (4-validate.md)
- Check content quality
- Verify factual accuracy
- Ensure compliance with guidelines

### 5. Review (5-review.md)
- Final editorial review
- Polish and refine
- Prepare for publishing

## Platform Integrations

Each platform has specific formatting requirements and best practices:

- **beehiiv.md** - Newsletter platform specifics
- **substack.md** - Substack formatting guidelines
- **ghost.md** - Ghost CMS integration
- **hashnode.md** - Hashnode community platform
- **medium.md** - Medium publication settings
- **devto.md** - Dev.to technical content
- **linkedin.md** - LinkedIn professional network
- **linkedin-post.md** - LinkedIn native posts
- **_schema.md** - Platform schema definitions
